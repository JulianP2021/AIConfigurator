Overview

The webserver provides two main workflows:

  • / — interactive comparison. Enter model parameters and one or more hardware/topology configs, then run simulations and get cost-vs-latency plots.
  • /import — import pre-generated result files from the command-line sweep scripts and render their specialised plots.

1. Interactive comparison

Use the form on the home page to define global parameters (model, ISL/OSL, users, batch size, S3 settings, etc.) and add hardware/topology configs. Each config row specifies prefill/decode hardware, node counts, GPU split, batch size, and a label.

The server runs each config in an isolated process and returns:

  • A summary of the best config by latency.
  • Cost-latency scatter plots (TTFT, TPOT, latency, KV upload/download).
  • A full comparison table and timing breakdown (hidden by default).

2. Importing sweep results

The import page accepts a results directory. The result type is detected automatically from the JSON file contents and filenames:

  • User sweep — output of configs/execute_user_sweep_config.py. Files are named results_users_<N>.json. Rendered plot: cost vs. users, coloured by deployment mode.
  • Hardware economics — output of configs/execute_hardware_economics_config.py. Files are named results_<focus>_<value>.json. Rendered plots: cost by user delay and price per user by user delay.

You can also paste a raw JSON array or {"results": [...]} object; the benchmark type is inferred from row metadata (users vs. user_delay_ms).

Generating sweep configs

Use the command-line scripts in configs/:

# Broad topology sweep across hardware and user counts
.venv/bin/python configs/create_user_sweep_config.py --config-name sweep.json
.venv/bin/python configs/execute_user_sweep_config.py --config sweep.json --results-dir ./results

# Fixed-topology hardware economics sweep (TTFT and user delay)
.venv/bin/python configs/create_hardware_economics_config.py --config-name he.json
.venv/bin/python configs/execute_hardware_economics_config.py --config he.json --ttft-values 10,20,50 --user-delay-values 20,50,100 --results-dir ./he_results

Plot storage

Plots are stored in memory keyed by UUID and served from /plot/<uuid>. They disappear when the server restarts, so export or screenshot results you want to keep.
